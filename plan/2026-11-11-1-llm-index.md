# Plan: nixarchy-llm-index v0.1

Builds v0.1 of `llm-index` on branch `feat/1-llm-index-v0.1` (from
`docs/1-llm-index-intent` once merged, or from it directly). The repository
holds only `LICENSE`, `README.md`, `.gitignore`, `.markdownlint.yaml`,
`intent/`, `spec/`; every code file below is new.

## Approved decisions (self-contained)

Everything a step needs; the spec is the long form.

### Product

- One Rust binary `llm-index`, subcommands `index` (long-running service, sole
  DB writer), `worker` (short-lived or watcher child of `index`), `mcp --tier
  public|private` (stdio, spawned per client session, read-only), `status`
  (CLI, reads DBs). x86_64-linux only. MIT.
- v0.1 formats: Markdown, plain text, HTML, PDF text layer, `.docx`, `.odt`,
  `.xlsx`, `.ods`, `.xls`, `.csv`, source code. No OCR, no `.pptx`.
- Bounds on the reference laptop (x86_64, 4 cores, 8 GB, no GPU): closure
  ≤ 500 MB incl. model; `mcp` RSS ≤ 100 MB idle and warm; indexing service
  cgroup `memory.peak` ≤ 1 GB; 10,000 mixed files ≤ 2 h; 100 local edits
  searchable ≤ 5 min.

### Dependencies

| Need | Crate / input |
| --- | --- |
| MCP | `rmcp` 3.x, stdio |
| SQLite | `rusqlite`, `bundled` feature (FTS5); no `sqlite-vec` |
| Embeddings | model `minishlab/potion-retrieval-32M` (512 dims, 129,210,456-byte float32 `model.safetensors`, `tokenizer.json`), pinned revision, `fetchurl` with hash; `tokenizers` with default features off (no download); `safetensors` (header parse only); `memmap2` in `index` only |
| Sandbox | `landlock` |
| Watch | `inotify` (non-recursive) |
| Walk | `ignore` 0.4 |
| Code | `tree-sitter` + grammars Rust, Python, Go, JavaScript, TypeScript, Nix, C, C++, Java, Bash, TOML, YAML, JSON |
| Text | `text-splitter` 0.33 |
| PDF | `pdfium-render` 0.9 against nixpkgs `pdfium` with V8 and XFA off |
| Sheets | `calamine` 0.38; `csv` 1.x |
| docx/odt | `zip` + `quick-xml` |
| HTML | `html2text` or `scraper`, whichever adds less closure |
| Hash | `blake3` |
| Syscalls | `rustix` or `libc` for `openat2`, `statx`, `prlimit` |

No GPU, ONNX, Ollama, database server, network listener. No GPL in direct
dependencies.

### Storage

- State dir: `$XDG_STATE_HOME/llm-index/` (HM, created by `index`) or
  `/var/lib/llm-index/<owner>/` (NixOS, `StateDirectory=`); option `stateDir`
  / config `state_dir`. Mode 0700, files 0600. `index` refuses to start if
  the state dir is on a network/FUSE fs (`statfs`) or a parent has
  `.stfolder`, `.sync`, `.dropbox`, `.nextcloudsync.log` or `.sync_*.db`.
  State dir is a built-in exclusion. Writes `CACHEDIR.TAG`.
- `public.db` and `private.db`, same schema, each file in exactly one.
  `mcp --tier public` opens only `public.db`, with no flag, path or tool that
  reaches `private.db`. `mcp --tier private` opens both.
- Schema per DB:
  - `roots(name, path, kind, share_id, state, reason, last_scan, queued,
    done, skipped_symlinks)`
  - `files(id, root_id, relpath, abspath, title, type, size, mtime_ns, blake3,
    state, reason)`, unique `(root_id, relpath)`
  - `chunks(id, file_id, ord, kind, start, end, decl_start, decl_end,
    heading_or_symbol, text, vec BLOB(512))`
  - `chunks_fts` (FTS5, chunk text), `files_fts` (FTS5, title + path); both
    `tokenize = "unicode61 remove_diacritics 2"`, **no porter**
  - `embed_cache(input_blake3 PRIMARY KEY, vector)`; key = BLAKE3(model_rev
    ‖ full embedding input incl. path/symbol prefix)
  - `validated(path_blake3, config_error)` (public.db: hashes only)
  - `meta(model_rev, schema_version)`
  - WAL mode; `index` writes, others read.
- Vectors: L2-normalised, ×127, round, clamp to int8. Similarity =
  `dot_i8(a, b)` Rust scalar SQL function. Order **DESC**.
- Titles: Markdown front-matter `title` or first H1; HTML `<title>`; PDF
  `Title` else first text line; docx/odt `dc:title` else first heading;
  sheets and code: filename.
- Roots canonical: absolute, no symlink component. `abspath = root path +
  relpath`. Nested roots: parent walk skips any directory that is another
  root.

### Search and tools

- `search(query, mode=hybrid|words|meaning, field=any|title|path, folder?,
  type?, after?, before?, limit?)`. Words = whole tokens, case/diacritic
  insensitive, `"…"` phrases. `title`/`path` search `files_fts`, one hit per
  file.
- Eligibility (SQL filters + `visible()`) before both legs. Words: BM25 over
  both FTS tables. Meaning: `ORDER BY dot_i8(vec, ?) DESC LIMIT`. RRF k=60.
  Private server: legs per DB; meaning merged by similarity; the two words
  lists enter RRF separately.
- Hit: `path, title, mtime, type, tier (private only), stale, lines
  (code: decl_start–decl_end) | page | sheet+rows, symbol|heading, passage
  ≤ 800 chars` (title/path hits: first chunk).
- `get(path, start?, end?, sheet?)`: pages (PDF), rows (sheets), lines
  (rest); ≤ 20,000 chars per call plus `next`. `recent(days, folder?,
  type?)`. `status()`. All `readOnlyHint`. Passages wrapped as untrusted with
  path; strip Unicode tag, bidi-override, zero-width chars at ingest.
- `mcp` memory: parse safetensors header once; `pread` each query token's
  2 KB row; never map or load the matrix.

### Authorization

- `visible(abspath) -> public|private|none`, a Rust scalar SQL function in
  every query's `WHERE`, each tool call in one read transaction. Strings
  only, never filesystem access: longest root whose path is a component-wise
  prefix gives the tier; no root → none; user exclusion or built-in denylist
  (lifts only for private roots) → none; root `config_error` → none.
- Re-read `config.toml` on mtime/inode change. Missing/invalid config → every
  tool errors (fail closed, no last-good fallback). Exclusions outside every
  root make config invalid.
- Validation (indexer, in workers under share rules): longest existing prefix
  of each root/exclusion path opened with `openat2(RESOLVE_NO_SYMLINKS)`;
  re-validated each scan of its root; stores BLAKE3 of validated path strings
  and a `config_error` flag (`ELOOP`) in `public.db`.
- Public server: removals and public→private apply at once. A newly added
  root or exclusion not yet validated, or `config_error`, closes **every
  public tool** with the generic error `index configuration is being
  checked` (no path). Owner decision: fail closed even when the share is
  hung. Private server applies new rules by string at once, never closes;
  it and `status` name the path.
- Public `status` lists only public roots.

### Indexing

- Discovery: `ignore` walker with `.gitignore`, `.git/info/exclude`, global
  gitignore, `.llmindexignore`, denylist, user excludes;
  `follow_links(false)`, `same_file_system(true)`. **Never execute `git`.**
- Format dispatch first: extension + magic (`%PDF-`; ZIP with
  `[Content_Types].xml` or `mimetype` for docx/xlsx/odt/ods; OLE2 `D0 CF 11
  E0` for xls); mismatch → skipped `mismatch`. CSV after text checks.
- Skip dirs/files: `.git/`, `node_modules/`, `vendor/`, `third_party/`,
  `target/`, `.venv/`, `venv/`, `__pycache__/`, `.direnv/`, `result*`, dirs
  with `CACHEDIR.TAG`, lockfiles, files > 50 MB. Text/code only: binary (NUL
  in first 8 KB or invalid UTF-8), minified (`.js .css .json .map`, mean line
  > 250), generated (`@generated` or `Code generated … DO NOT EDIT` in first
  4 KB).
- Denylist (all tiers; liftable for private only): `.env*`, `*.pem`,
  `*.key`, `id_rsa*`, `id_dsa*`, `id_ecdsa*`, `id_ed25519*`, `*.p12`,
  `*.pfx`, `*.kdbx`, `*.age`, `.netrc`, `.git-credentials`, `.npmrc`,
  `.pypirc`, `.docker/config.json`, `.cargo/credentials*`, `.ssh/`,
  `.gnupg/`, `.password-store/`, `.aws/`, `.azure/`, `.kube/`,
  `.config/gcloud/`, `.config/gh/`, `.config/sops/`,
  `.local/share/keyrings/`, `.claude/`, `.codex/`, `.gemini/`,
  `.antigravity/`, `.config/Antigravity/`, `.mozilla/`, `.thunderbird/`,
  `.config/google-chrome/`, `.config/chromium/`, `.config/BraveSoftware/`,
  `.config/vivaldi/`, `/run/`, `/proc/`, `/sys/`, state dir. Own matcher, not
  gitignore: case-insensitive on the absolute path; leading `/` anchors at
  fs root; any other pattern matches any run of components at any depth
  (as `**/`); trailing `/` = directory and below.
- Open: `openat2(root_fd, relpath, O_RDONLY | O_NOFOLLOW, RESOLVE_BENEATH |
  RESOLVE_NO_SYMLINKS | RESOLVE_NO_MAGICLINKS | RESOLVE_NO_XDEV)`, `fstat`
  regular file. Root acquired with `openat2(AT_FDCWD, path, O_RDONLY |
  O_DIRECTORY, RESOLVE_NO_SYMLINKS | RESOLVE_NO_MAGICLINKS)` (not `O_PATH`):
  `ELOOP` → `config_error`, `ENOENT`/dead → `offline`.
- Chunking: tree-sitter declarations, siblings packed to ~512 tokens, large
  declarations split with `decl_start/decl_end` on every part; stored text =
  original source; path+symbol prefix only in embedding input. Markdown by
  headings; other text `text-splitter`; PDF by page; sheets by sheet + row
  block.
- Tier routing: longest root; default private. Cross-tier move = delete from
  one DB and insert in the other, public delete first.

### Workers, shares, scheduling

- Coordinator never touches a root; JSON lines over a pipe to workers.
- Worker start order: open `/proc/self/mountinfo` and global gitignore (keep
  fds); `oom_score_adj = 1000`; `RLIMIT_AS = 4 GB`; acquire root fd; apply
  Landlock (handles read + write: read beneath root fd and `/nix/store`, no
  write, ABI ≥ 4 no TCP); then take jobs. Single-threaded. Mount checks
  re-read the kept fd from offset 0.
- Limits: scan 10 min, extract 30 s; zip members ≤ 100× archive and ≤
  500 MB total. OOM-killed while another worker ran → one solo retry; else
  `failed`, retried only on size/mtime change.
- Watcher worker per local root (outside pool and share rule): watches each
  dir with `IN_ONLYDIR | IN_DONT_FOLLOW`, skips mount points strictly below
  the root's containing mount, forwards events, debounce 2 s. Progress rule
  while adding watches; trip → kill, abandon, root `degraded`, polled by
  scan workers every 2 min; no new watcher until reaped. `ENOSPC`,
  `IN_Q_OVERFLOW`, watcher failure → `degraded` + immediate reconciliation.
  Daily full reconciliation.
- Coordinator `poll`s `/proc/self/mountinfo`; on change re-derives
  identities and scans roots whose containing mount changed.
- Share identity `(fstype, source, mount root, mount point)` derived by
  string match against `mountinfo` **before** any I/O. Network fstypes: NFS,
  CIFS/SMB2, FUSE (`fuse.sshfs`, `fuse.rclone`, others), `autofs`. Expected
  identity from `share = "…"` or first successful scan. autofs: open root
  (triggers mount), re-derive. Deeper mount replaces recorded identity only
  while the root has **no indexed files**; else any change is a mismatch.
- Network roots: poll every `interval` (default 15 min), `statx` default
  sync mode, `(relpath, size, mtime_ns)`. Mount check before and after scan
  (identity + root fd `st_dev`); mismatch/unmount → `offline (identity
  mismatch)`, result discarded.
- One live worker per share (scan or extract), counted until `waitpid`
  reaps it; across a re-derive it counts against both old and new identity.
  No progress for 30 s (progress = entries listed / bytes read from the I/O
  thread) → `SIGKILL`, abandon, share `offline`; nothing new on that share
  until reaped **and** backoff (1 → `backoff_max` 60 min, doubling) expired.
- Pool `workers` (default 2, minimum 2) counts live non-abandoned workers;
  network jobs ≤ `workers - 1`. `TasksMax` = 16 + workers + local roots +
  network roots + 8.
- Delete only after a complete scan that passed both mount checks. Offline
  entries served `stale: true`.

### Service and sandbox

- Unit: `Nice=19`, `IOSchedulingClass=idle`, `CPUWeight=20`,
  `MemoryHigh=768M`, `MemoryMax` = `memory_max_mb` (1024), `OOMPolicy=continue`,
  `TasksMax` as above, `NoNewPrivileges`, `RestrictAddressFamilies=AF_UNIX`,
  `SystemCallFilter=@system-service @sandbox`; NixOS also `PrivateNetwork`,
  `User=<owner>`, `StateDirectory`. **No** `ProtectSystem`, `ProtectHome`,
  `PrivateTmp`, `ReadWritePaths`.
- Coordinator Landlock at start: handles write (and TCP on ABI ≥ 4) only;
  write allowed beneath state dir and `/proc`. Without Landlock `index`
  refuses to start; no override.

## Steps

Every step: branch `feat/1-llm-index-v0.1`; commit per step as
`feat(llm-index): <step> (#1)`; run `cargo fmt --check`, `cargo clippy -D
warnings`, `cargo test` and `nix flake check --no-build` (from step 2 on)
before handing back. Traps for every step: never run `git` from the program;
no network at build or test time; no secrets in the store; keep Landlock
order exactly as written.

1. **Feasibility record** → `docs/feasibility.md` (new). Pin `nixpkgs` (a
   recent `nixos-unstable` rev) and record: (a) whether the pinned NixOS
   default `security.lsm` includes `landlock` (the reference host runs
   `lockdown,capability,landlock,yama,bpf,ima`); (b) pinned `pdfium`
   derivation has V8 and XFA off, override if not; (c) HF revision hash and
   SHA-256 of `model.safetensors` and `tokenizer.json` for
   `minishlab/potion-retrieval-32M`, and its licence; (d) exact versions and
   licences of every crate in the table, and that `tokenizers` builds without
   default features; (e) `@sandbox` contains `landlock_create_ruleset` in the
   pinned systemd; (f) `html2text` vs `scraper` closure delta.
   → verify: every item has a value or a named blocker. Stop and report to
   the owner on any blocker.
   Traps: done by the lead, not a coder; no code.

2. **Skeleton** → `Cargo.toml`, `Cargo.lock`, `src/main.rs` (clap
   subcommands, stubs), `flake.nix`, `flake.lock`, `nix/package.nix`
   (`rustPlatform.buildRustPackage`, model via `fetchurl` into
   `share/llm-index/models/`, pdfium linked), `nix/checks/closure.nix`.
   → verify: `nix build .#default`; `nix path-info -S ./result` ≤ 500 MB;
   `./result/bin/llm-index --help`.
   Traps: `cargoLock.lockFile`, no IFD; model hashes from step 1.

3. **Storage, embedding, ranking** → `src/db.rs` (schema, migrations, WAL,
   `dot_i8`, open modes: public-only vs both), `src/embed.rs` (tokenizer,
   safetensors header, `pread` rows for `mcp`, `memmap2` for `index`, mean
   pooling, normalise, quantise), `src/rank.rs` (BM25 query builders, meaning
   leg, RRF, cross-DB merge).
   → verify: unit tests: `dot_i8` DESC puts the most similar known vector
   first; filtered meaning search where every globally nearest chunk is
   ineligible still returns the nearest eligible one; embed cache key changes
   with path prefix; int8 vs float32 top-5 overlap reported; `mcp`-mode embed
   RSS growth after 1,000 distinct queries < 10 MB.
   Traps: no `sqlite-vec`; no porter; never load the matrix in `mcp` mode.

4. **Config, denylist, authorization** → `src/config.rs` (parse, validate:
   canonical-looking absolute paths, exclusions under a root, workers ≥ 2;
   invalid → error), `src/deny.rs` (matcher as specified), `src/auth.rs`
   (`visible()` SQL function, longest-prefix root, lifts only for private,
   validated-hash gate, generic public error).
   → verify: unit tests for nested private root under public, removed root,
   changed root path, new unvalidated exclusion closes public with a message
   containing no path, removal applies without validation, `config_error`
   closes public, missing/corrupt config errors, `.config/gcloud/` matches
   under `/home/x`, `id_map.rs` allowed, root inside `.ssh/` denied, lift
   ignored for public root, `/run/user/1000/agenix/x` denied.
   Traps: no filesystem calls in `auth.rs` (enforce with a test that runs it
   under a Landlock ruleset denying all reads); fail closed on any parse
   error.

5. **Worker runtime, sandbox, scan** → `src/worker/mod.rs` (JSON-lines
   protocol, progress messages from the I/O thread), `src/worker/sandbox.rs`
   (exact start order, Landlock rules, `oom_score_adj`, `RLIMIT_AS`),
   `src/worker/scan.rs` (root acquisition via `openat2`, `ignore` walk,
   symlink count, nested-root skip, `statx`, mount checks from kept fd,
   validation job for config paths), `src/worker/watch.rs` (watcher
   worker).
   → verify: tests: root swapped for a symlink before acquisition →
   `config_error`; directory beneath root swapped between list and open →
   not read; nested root files listed once; a worker cannot create a file in
   its root or open TCP; reads `mountinfo` after restrict; `oom_score_adj`
   reads 1000; watcher skips a submount.
   Traps: `O_RDONLY` not `O_PATH` for root; set `oom_score_adj` before
   Landlock; single-threaded except the progress pipe.

6. **Extractors and chunkers** → `src/extract/{mod,text,markdown,html,pdf,
   docx,odt,sheet,csv,code}.rs`, `src/chunk.rs`, `src/sanitize.rs`
   (strip tag/bidi/zero-width chars).
   → verify: fixture unit tests per format (titles, page/sheet/line ranges,
   declaration ranges for a split function, docx with NULs indexed, `.docx`
   that is not ZIP → `mismatch`, long-line HTML indexed, minified JS skipped,
   zip bomb rejected by the guard).
   Traps: format dispatch before text heuristics; pdfium with no JS; zip
   guard counts declared and actual sizes.

7. **Coordinator** → `src/index/{mod,shares,sched,store,validate,
   statedir}.rs`: state-dir checks and `CACHEDIR.TAG`; coordinator Landlock;
   mountinfo parse and `poll`; share identity and replacement rule; pool,
   per-share rule with dual charging, abandonment, backoff, solo OOM retry;
   watcher lifecycle; scan/extract queues; tier routing and cross-DB moves;
   purge of now-invisible rows; deletion after complete scans; `roots`
   status columns; validation hashes.
   → verify: unit tests with a fake worker spawner and fake clock: never two
   live workers per share across three outage cycles and an autofs
   re-derive; local jobs keep a slot with two hung shares; healthy third
   share still scanned; partial/mismatched scan deletes nothing; empty root
   adopts deeper mount, non-empty root does not.
   Traps: the coordinator must not open any root path (test: run it under a
   Landlock ruleset denying reads beneath the fixture roots).

8. **MCP server and status CLI** → `src/mcp.rs` (`rmcp` stdio, tools,
   untrusted wrapping, error mapping), `src/status.rs`.
   → verify: scripted stdio session: search, get with `next`, recent, status;
   public status hides private roots; a file indexed after the session
   opened appears in the next search; `mcp` idle RSS printed.
   Traps: public mode must not accept any option naming `private.db`.

9. **Nix modules** → `nix/hm-module.nix`, `nix/nixos-module.nix`,
   `share/AGENTS.snippet.md`, `nix/config.nix` (TOML generation shared by
   both).
   → verify: `nix flake check` eval of both modules with a minimal config;
   `programs.mcp.servers` has `llm-index-public` only; `TasksMax` computed;
   assertion fails for `workers = 1` and an exclusion outside roots.
   Traps: no mount-namespace options; NixOS module has no `registerPublic`.

10. **Flake checks** → `nix/checks/{fixture,tier,reclassify,sandbox,network,
    watch,access,freshness,modules}.nix`, fixtures under `tests/fixtures/`,
    40 labelled queries in `tests/queries.toml`.
    → verify: `nix flake check` passes; each check matches the spec's
    Verification section, including: recall@5 ≥ 0.8; reclassification (a)–(h)
    incl. symlinked exclusion and hung share keeping public closed;
    two-node NFS with start-while-down, three backoff cycles, at most one
    worker per share at every sample, replacement export, automount,
    deeper empty mount, remote edit within interval + 60 s, two dead + one
    healthy share; watch limits and overflow with 100 edits ≤ 5 min; other
    user cannot read state; Landlock-less boot refuses to start.
    Traps: VM tests use short `interval` and `backoff_max`; NFS server with
    `hard` mounts on the client to reproduce D-state.

11. **Benchmark and docs** → `bench/corpus.nix` (pinned fixed-hash sources,
    10,000 files: 40% code, 20% Markdown/text, 10% HTML, 15% PDF ~10 pages,
    10% docx/odt, 5% sheets/CSV, BLAKE3 manifest), `bench/run.sh`,
    `docs/benchmark.md` (procedure + table for results), `README.md`
    (install, options, tiers, the sync caveat, Landlock requirement).
    → verify: `nix build .#bench-corpus` reproduces the manifest; the lead
    runs `bench/run.sh` on the reference laptop and records time, cgroup
    `memory.peak`, `mcp` idle/warm RSS, 100-edit latency.
    Traps: the benchmark run itself is manual, by the owner or lead, not CI.

## Rollback

All work is new files on `feat/1-llm-index-v0.1`; nothing outside this
repository changes. Roll back by not merging the branch, or `git revert` of
the merge on `main`. Users who enabled the module remove the import; the
state directory can be deleted (`rm -r ~/.local/state/llm-index`), and no
indexed folder is ever written.
